Mac 연결 프로그램 설치 방법

다운로드한 저장소의 최상위 폴더에서 다음 명령을 실행하세요.

npm ci
npm run build -w dualread-personal-native
node personal/native/install.mjs

Edge에서는 마지막 명령 끝에 edge를 붙이세요. 설치 후 이 화면을 다시 열고 로그인하세요.

OpenAI Chat Completions 호환 주소를 입력하세요.
서버와 모델이 지원하는 추론 강도를 선택하세요. 기본값을 고르면 서버 설정을 따릅니다.
