번역 연결 설정

선택한 글을 이 Mac의 연결 프로그램을 통해 OpenAI에 보냅니다. 번역에는 ChatGPT 플랜 사용량이 적용됩니다.

ChatGPT 사용량 관리
Mac 연결 프로그램 설치 방법

다운로드한 저장소의 최상위 폴더에서 아래 명령을 실행하세요.

npm ci
npm run build -w dualread-personal-native
node personal/native/install.mjs

Edge를 사용한다면 명령 끝에 edge를 붙이세요. 설치 후 이 설정 페이지를 다시 열어 로그인하세요.

OpenAI Chat Completions 호환 주소를 입력하세요.
키는 현재 브라우저 세션에만 보관합니다.

ChatGPT 플랜을 사용합니다

DualRead의 구독 연결 번역은 내 ChatGPT 플랜 사용량에 포함됩니다. ChatGPT 설정에서 사용량을 확인할 수 있습니다.
